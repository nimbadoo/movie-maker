# خروجی کامل قسمت۲ — نسخهٔ۵

![پخش خروجی کامل](EP02-full-with-approved-SH03.mp4)

مدت۵۱٫۸ثانیه؛ اندازهٔ `360×640` و `30fps`. برداشت اصلی۱۰ثانیه‌ای نمای۳، پس از پذیرش صریح کاربر، از۵٫۷تا۱۵٫۷ثانیه جایگزین نمای قدیمی شد. برش کوتاه بررسی وارد تدوین نشد؛ نمای۱۳ اصلاح‌شده و بقیهٔ محتوای نسخهٔ۴ محفوظ‌اند. سرعت، دیالوگ و زمان داخلی برداشت تازه تغییر نکرده‌اند. هیچ تولید یا مصرف اعتبار تازه انجام نشد.

فایل کامل بدون خطای رمزگشایی بررسی و فریم‌های اتصال دیده شدند. قضاوت نهاییِ اتصال صوتی با پخش کاربر است؛ تأیید برداشت توسط کاربر، به‌عنوان تأیید ابزار خودکار معرفی نمی‌شود.
