# نسخهٔ اولیهٔ تدوین سکانس اول

وضعیت: این نسخه در ۲۰۲۶/۱۰/۱۳ توسط کاربر تأیید شد؛ خروجی پذیرفته‌شدهٔ فعلی قسمت اول است. نام فایل برای حفظ سابقه تغییر نکرده است.

[پخش نسخهٔ اولیه](EP01-SC01-first-cut-v1.mp4) — حدود ۳۸ ثانیه؛ ۱۶ نما به ترتیب روایت. SH10 و SH09 از برداشت دوم‌اند.

[فهرست دقیق منبع، هش، ورود/خروج و دلیل برش](timeline.json) و [نمونه‌فریم‌های حرکت](motion-samples.jpg).

برش‌های بیرونی با تشخیص گفتار و حاشیهٔ محافظ اعمال شدند؛ سرعت پخش و مکث داخلی تغییر نکرد. فایل‌های میانی به ترتیب 01 تا16 نام دارند و concat.txt ترتیب مونتاژ را ثبت می‌کند. خروجی H.264 عمودی 360×640 با نرخ ثابت ۳۰ فریم و AAC48kHz برای بازبینی است؛ افزایش اندازهٔ مصنوعی انجام نشده.

این نسخه مستر نهایی نیست. تلفظ، هماهنگی لب، ثبات صدای شخصیت‌ها و اتصال گذاشتن سینی هنوز نیازمند بازبینی کامل شنیداری/تصویری‌اند. فایل‌های MP4 در Drive نگه‌داری می‌شوند و وارد تاریخچهٔ Git نمی‌شوند؛ گزارش و نقاط برش ثبت می‌شوند.
