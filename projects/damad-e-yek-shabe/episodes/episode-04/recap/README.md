# آنچه گذشت — نسخهٔ منتخب۳

![مرور تأییدشده](EP04-previously-v3.mp4)

مدت۸٫۹۱۷ثانیه، نزدیک به سیاه‌وسفید با اشباع۱۵درصد؛ شروع داستان جاری رنگ کامل دارد. کاربر همین نسخه را پذیرفت. [ثبت انتخاب و خروجی](manifest-v3.json).

۱. قسمت۱، نمای۳: «مَن یِکی دیگِه رُو دوسْت دارَم.»؛ منبع۱٫۲۵تا۳٫۴۱۷ثانیه.
۲. قسمت۲، نمای۸: «تُو بازیگَری. فِکْر کَرْدَم می‌تونی یِه شَب این نَقْشُو بازی کُنی.»؛ منبع۱٫۲۵تا۵٫۵۸۳ثانیه.
۳. قسمت۳، نمای۱۴: «پَس باهاشون حَرْف بِزَنین.»؛ منبع۰تا۲٫۴۱۷ثانیه. نوشتهٔ «صحبت با مادر سامان» مرجع ضمیر را روشن می‌کند.

صدا و سرعت همان منابع اصلی‌اند؛ تولید گفتار/تصویر تازه انجام نشد. [منابع و محدوده‌ها](manifest-v2.json) و [برچسب‌های تصویری](recap-labels-v2.ass) حفظ شده‌اند. منابع قسمت‌های قبل جابه‌جا یا حذف نشده‌اند.

نسخه‌های رسانه‌ای۱و۲منسوخ و حذف شدند؛ ثبت‌های قدیمی برای سابقهٔ تصمیم باقی‌اند. مرجع کل قسمت [بستهٔ منتشرشده](../publishing/manifest.json) است.
