# کاور قسمت سوم؛ تأییدشده

[![کاور قسمت سوم](EP03-cover-v1.png)](EP03-cover-v1.png)

هماهنگ با کاورهای پذیرفته‌شدهٔ قسمت‌های۱و۲، با چهره و لباس نازلی، سامان و مادر در قسمت سوم. [پرامپت کامل](cover-v1-prompt.txt)، [منابع و اثرانگشت](cover-v1.json)، [بررسی](review.md). ابزار داخلی `imagegen` استفاده شد؛ اعتبار `Flow` مصرف نشد. این پوستر مرجع تازهٔ هویت یا پلان صحنه نیست. کاربر با گزینهٔ «تأیید کاور و کپشن؛ منتشر نکن» همین نسخه را پذیرفت؛ انتشار اجازه ندارد.
